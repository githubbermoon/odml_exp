Ambient cognition layer for on-device Gemma 4 + LiteRT-LM + MediaPipe

What this project does

MediaPipe perceives continuously, Gemma reasons sparsely, and GhostOS stores compressed semantic memories without streaming continuous raw video.

Example: lose focus, raise a hand, or point at a whiteboard. GhostOS infers state, intervenes subtly, and remembers the semantic moment locally.
