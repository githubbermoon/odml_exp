What this project does

Runs a stable phone-to-Mac on-device AI demo: MediaPipe compresses camera perception into semantic events, then Gemma 4 reasoning streams back through LiteRT-LM.

Example: point the Samsung camera at a whiteboard, tap Inspect pipeline, and see the local Gemma path explain the ODML stack.
